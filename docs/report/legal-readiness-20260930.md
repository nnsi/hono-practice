# 規約と実装の照合・文面修正（2026年9月30日）

ユーザー依頼により、日英のプライバシーポリシー・利用規約、特商法表記、削除確認文を更新した。文面修正は完了したが、削除運用と委託先の確認が完了したことを意味しない。デプロイ・改定通知は行っていない。

## 修正した文面

- 日本語「6か月後に完全削除」と英語「30日以内に削除」の不一致を解消。設定での退会は無効化であり、物理削除は別途管理者処理、自動削除は未実装という実態を両言語で説明する。削除の申出・対応状況・予定・結果の問い合わせ先を記載。既に受け付けた申出の旧条件の期限は延長しない。
- 英語にだけあった、未確認のログ90日・問い合わせ1年の削除保証を外した。両言語とも、利用目的や法令上の必要性による保存基準と、不要となった情報の削除を記載。無期限保存を認めるための変更ではない。
- OpenRouterとAIモデル提供者への送信内容・目的・送信タイミングを追加。AIを使わない通常の保存・同期との違いも記載。未確認の保持・学習条件を断定しない。
- 無料利用者もRevenueCatのログイン・利用権確認の対象になることを記載。エラー種別・利用者識別子・認証診断情報等を追加し、送信項目の誤った限定を修正。
- 外国移転先を一律に米国とする表現、全提供先で同一のDPA/SCCが確認済みと受け取れる表現を修正。事業者所在地と処理国を区別。
- 英語の「入力したことでGDPR上の明示的同意になる」という記述を削除。基本の開示等手数料と一般利用者への回答目安を日英で揃えた。
- 退会・アンインストールではストア課金が自動解約されないことと、ストアでの解約方法を、日英の規約・PP・削除確認、特商法表記に追加。購入の復元は元のActikoアカウントに固定。
- 規約・PPの同意記録用versionを2026-09-30へ更新し、表示も同日の「改定日」に変更。改定日を既存ユーザーへの適用開始日とみなすものではない。

## 公開前に残る運用

1. **削除の実行と通知**: ユーザー回答で手動運用も未実施と確認済み。退会したユーザーの処理対象を把握し、削除対象・法定保存分・バックアップの扱い、実施期限、完了通知を定めて実行する。文面変更だけではAppleのアカウント削除要件を満たしたとは判断できない。問い合わせをさせるだけでアプリ内削除を代替しない。
2. **AI・海外移転**: 実際に使うモデル/事業者/処理国、保存・学習設定、委託条件と必要な同意を確認する。PP掲載だけで個別同意が成立したと扱わない。
3. **改定通知と適用日**: 現行の規約・PPにある事前通知を履行する。重要な変更は30日前通知。既存ユーザーへの適用日を別途決め、必要な個別同意を取得する。新versionのコード反映だけでは既存同意の更新にならない。
4. **本番表示・ストア申告**: 事業者名・問い合わせ先の環境変数、ストアのプライバシー申告、購入・解約の実導線を確認する。所在地などを請求時開示にする場合は実際に対応できる体制が必要。

## 検証

- Webのプライバシーポリシー表示・問い合わせ遷移と、設定画面の日英の法務モーダル・削除確認を隔離PGliteのE2E環境で確認。4 tests passed。
- 375px幅で日英の削除確認文・ボタンを確認。E2E起動時はTailwindのcontent解決がリポジトリroot基準になるため、表示確認ではアプリの設定とソースからアプリdirectoryで生成したCSSを読み込ませた。実機nativeの表示確認ではない。
- 全アプリの型チェックと変更ファイルのBiome checkを実施。一時的な文面確認用E2Eファイルは検証後に削除済み。
- 本番DB・外部サービスへの書込み、配信は行っていない。
