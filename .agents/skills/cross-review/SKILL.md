# クロスレビュー

[レビュー共通手順](../multi-review/references/review.md) を使い、ロジック・セキュリティと設計・テストの 2 観点を独立にレビューする。

利用可能な sub-agent に分担する。別エンジンが明示指定された場合はそれに従い、起動できない場合はその制約を報告する。CLI の別モデル起動や課金を無断で追加しない。sub-agent が利用できなければ自身で観点を分け、独立レビュー未実施と明記する。
