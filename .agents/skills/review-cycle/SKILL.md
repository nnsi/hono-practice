# レビューと修正

1. 指定されたレビュー方法を使う。指定がなければ [cross-review](../cross-review/SKILL.md)、広い専門レビューは [multi-review](../multi-review/SKILL.md)。
2. 指摘を実コード・再現条件で確認し、依頼範囲の問題を修正する。偽陽性は理由を記録する。
3. 変更した挙動のテスト・型・lint を確認し、レビュー担当に指摘の解消と修正の副作用を確認させる。
4. 確認できた問題が解消し、関連検証が通れば完了。全員の定型 LGTM を待つためだけに反復しない。

同じ指摘が解決せず繰り返す、または新しい根拠が出ない場合は反復を止め、未解決事項と必要な判断を報告する。ラウンド数によって重大な問題を無視する閾値変更はしない。
