# 並列作業

- 分担は独立して進められる作業に使う。探索・実装の強制委譲、固定人数・モデル・effort は設けない。
- 各担当へ作業ディレクトリ、目的、編集範囲、参照先、完了条件を渡す。
- 編集ファイルが重ならないように分ける。共有 interface 変更は先に調整する。全体 formatter を他担当の編集中に走らせない。
- 利用可能な実行手段と権限を使う。権限バイパスを既定にしない。別 CLI の利用や追加課金は依頼範囲とルート AGENTS.md の条件を守る。
- 担当の結果は差分と検証の証拠で確認する。同じ検証を親が再実行すること自体は目的にしない。
